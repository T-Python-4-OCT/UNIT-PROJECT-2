# Atlas media rules

- Use professionally produced photographs and footage with sharp detail, balanced exposure, and intentional framing. Reject casual snapshots, screenshots, low-resolution crops, and visible watermarks.
- Use photographs without recognizable faces, including in the full-size viewer.
- Use real footage for project videos and verify the source and embedding or reuse terms. Label regional context accurately.
- Do not add media credits. Use only media that permits credit-free presentation.
